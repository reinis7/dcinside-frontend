# 7. 검색과 전체보기 (구현)

## 통합검색 페이지

- Route: `/search/q?keyword=`  
- 페이지: `src/pages/search/SearchQueryPage.jsx`  
- 탭: 갤러리 / 게시물 / (동영상 준비 중 카피)  
- 갤러리 매칭: 이름 또는 slug/ID 위주 (UI 안내 문구와 일치)

## 갤러리 전체보기 오버레이

- 컴포넌트: `src/components/gall/GalleryAllViewSearch.jsx`  
- 마운트: `GallHomePage`, `GallMinorIndexPage`, `GallMiniIndexPage`, `GallPersonIndexPage`  
- prop `galleryTypeName`: `"메인"` | `"마이너"` | `"미니"` | `"인물"`  
- 텍스트 검색: GraphQL `galleries(where: { search })` 후 **client filter** by type name  
- 초성/카테고리: 타입 스코프 topic tree  
- 추천: top/hot galleries  
- 닫기: Esc, outside click  

## 최근 방문

- `src/utils/recentGalleriesStorage.js` — `{ date, items }`, 하루 단위, max 5  
- tracker: `RecentGalleryVisitTracker` in gall layout  
- UI: `Header.jsx`
