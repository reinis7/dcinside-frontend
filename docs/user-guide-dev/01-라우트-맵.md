# 1. 라우트 맵

정의 위치: `src/App.jsx`, `src/routes/gallRoutes.jsx`, `signRoutes.jsx`, `searchRoutes.jsx`, `wwwRoutes.jsx`.

## WWW / 홈

| URL | 페이지 |
|-----|--------|
| `/`, `/www` | 사이트 홈 |

## 가입 · 로그인

| URL | 역할 |
|-----|------|
| `/sign/login` | 로그인 (`?s_url=` 복귀) |
| `/sign/register` | 가입 진입 → agree로 유도 |
| `/sign/join/agree` | 약관 동의 |
| `/sign/join/info` | 식별 코드·비번·닉네임 |
| `/sign/join/security` | 보안 코드 · 등록 실행 |
| `/sign/join/done` | 완료 |

## 갤러리 인덱스

| URL | 종류 |
|-----|------|
| `/gall` | 메인 |
| `/gall/m` | 마이너 |
| `/gall/n` | 미니 |
| `/gall/p` | 인물 (`/gall/person` → redirect) |

## 갤러리 생성 (보통 `RequireAuth`)

| URL | 종류 |
|-----|------|
| `/gall/create` | 메인 |
| `/gall/m/create` | 마이너 |
| `/gall/n/create` | 미니 |
| `/gall/p/create` | 인물 |

`createTopicKeyFromPathname` (`galleryCreatePaths.js`) 로 minor/mini/main/person 구분.

## 게시판

| 종류 | lists / view / write base |
|------|---------------------------|
| 메인 | `/gall/board/...` |
| 마이너 | `/gall/mgallery/board/...` |
| 미니 | `/gall/mini/board/...` (`ngallery` → mini) |
| 인물 | `/gall/p/board/...` |

쿼리: `id` = 갤 slug/식별자, 글 보기·쓰기는 `no` 등.

## 검색

| URL | 역할 |
|-----|------|
| `/search/q?keyword=` | 통합검색 페이지 |

「갤러리 전체보기」는 **별도 route 없음** — 인덱스 위 오버레이 (`GalleryAllViewSearch`).
