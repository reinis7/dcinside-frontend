# 0. 개발자 가이드 개요

## 범위

| 포함 | 제외 |
|------|------|
| SPA 라우트, 화면 컴포넌트 경로 | 서버(PHP/WP) 내부 구현 상세 (추정만 기술) |
| 클라이언트 검증 규칙 | 인프라/배포 전체 가이드 |
| GraphQL mutation/query 필드명 | 디자인 시스템 토큰 문서 |

스택 요약: **Vite + React + React Router + Apollo Client**.

## 디렉터리 감각

```
src/
  pages/sign/          # 가입·로그인
  pages/gall/          # 갤 인덱스·게시판·생성
  pages/search/        # 통합검색
  routes/              # gallRoutes, signRoutes, …
  auth/                # joinValidation, register API
  components/gall/     # 전체보기, 최근 방문 등
  api/                 # 오류 메시지 로컬라이즈 등
```

## 이용자 문서와의 관계

- **general**: 무엇을 누르면 되는지  
- **dev (이 문서)**: 어떤 URL·검증·mutation으로 동작하는지
