# 3. 갤러리 종류 (프론트 분기)

이용자 카피·고르는 법은 general 문서 참고.  
여기서는 **코드 분기**만.

## path → type

| path 힌트 | topic key | board base |
|-----------|-----------|------------|
| `/gall` (create 제외 main) | main | `/gall/board` |
| `/gall/m` | minor | `/gall/mgallery/board` |
| `/gall/n` | mini | `/gall/mini/board` |
| `/gall/p` | person | `/gall/p/board` |

helpers: `galleryCreatePaths.js`, `gallBoardPaths.js`, `dcinsideGalleryLinks.js`.

## 생성 폼 컴포넌트

| key | 컴포넌트 | 특이 입력 |
|-----|----------|-----------|
| main | `MainGalleryCreateForm` | reason 필수, promote agree 없음(메인) |
| minor | `MinorGalleryCreateForm` | reason, promote agree, 중복 안내 모달 |
| mini | `MiniGalleryCreateForm` | visibility public/private, reason 자동 문자열, promote agree 없음 |
| person | `PersonGalleryCreateForm` | reason, promote 관련 체크 가능 |

상태·제출: `GallCreateStubPage.jsx`.

## galleryTypes 매칭

`GALLERY_TOPICS_QUERY` 로 topics + types 로드 후  
`galleryTypeHintFromPath` (메인/마이너/미니/인물)로 `gallery_type` databaseId 선택.

## payload 차이 (요약)

- 공통: name, description, slug, gallery_type, galleryTopicId  
- mini: `visibility`, reason 고정 `"미니 갤러리 개설"`  
- minor/mini: 추가로 `galleryId: slug` 시도 후 schema mismatch 시 retry without
