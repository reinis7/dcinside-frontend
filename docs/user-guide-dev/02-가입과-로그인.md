# 2. 가입과 로그인 (개발)

## UI 단계

1. Agree — 필수 약관, `location.state`에 동의 흔적  
2. Info — username / password / nickname / email(optional)  
3. Security — `registerUser` 호출 후 자동 로그인 → done  
4. Done

관련 페이지: `src/pages/sign/SignJoin*.jsx`, `SignLoginPage.jsx`, `SignRegisterPage.jsx`.

## 클라이언트 검증 (`joinValidation.js`)

| 필드 | 규칙 |
|------|------|
| username (식별 코드) | `^[A-Za-z0-9][A-Za-z0-9_-]{2,19}$`, 한글 거부 |
| password | 길이 ≥ 8 |
| nickname | trim 후 2–20자 |
| email | optional; 있으면 간이 이메일 패턴 |

한글 username은 서버에서 strip → empty → `username is required` → `firstGraphQLErrorMessage` 가 「식별 코드를 입력해 주세요」로 로컬라이즈될 수 있음.

## 등록 API

- `src/auth/registerApi.js` (또는 register 관련 모듈) — GraphQL/REST 호출  
- 스키마에 captcha 필드 없음; 프론트 캡차 UI 제거됨  
- 성공 후 세션/토큰 저장 후 done 화면

## 로그인

- `/sign/login` — 식별 코드 + 비밀번호  
- 실패 메시지는 `firstGraphQLErrorMessage.js` 경유 한글화
