# 일반 이용자 가이드 (user-guide-general)

**코딩·API를 몰라도 되는** 이용 안내입니다.  
버튼·메뉴·주의사항만 다룹니다.

> 개발자용(요청/검증/라우트 등)은 → [user-guide-dev](../user-guide-dev/README.md)

---

## 이 가이드로 할 수 있는 것

- 회원가입(고정닉)부터 로그인까지 따라 하기
- 메인 · 마이너 · 미니 · 인물 갤러리가 **이용 목적**에서 어떻게 다른지 알기
- 갤러리 찾기(전체보기 · 통합검색 · 최근 방문)
- 새 갤러리 신청하기와, 신청 후 **승인될 때까지** 어떻게 되는지 알기
- 자주 하는 실수와 주의점 확인하기

## 자주 쓰는 메뉴

| 사이트 홈 | 왼쪽 위 로고 |

| 마이너 갤러리 | 상단 **마이너갤** |
| 미니 갤러리 | 상단 **미니갤** |
| 인물 갤러리 | 상단 **인물갤** |
| 회원가입 | 상단 **회원가입** |
| 로그인 | 상단 **로그인** |
| 검색 | 상단 검색창 |
