# 동영상 04 — 미니 갤러리 만들기와 승인

**완성 파일:** `04-create-mini-and-approval.mp4`  
**플레이스홀더:** [04-create-mini-and-approval.placeholder.html](./04-create-mini-and-approval.placeholder.html)

## 목표

1. `/gall/n/create`에서 공개·이름·주소·카테고리·동의를 채운다.  
2. 잘못된 입력이면 **실패 이유**가 뜬다는 것을 보여 준다.  
3. 성공 시 「생성 요청 완료」이며, **심사·허가**는 운영 측에서 이뤄진다는 점을 설명한다.

## 촬영 순서

| 시간 | 화면 | 말할 내용 |
|------|------|-----------|
| 0:00 | 로그인 상태 | “갤러리 만들기는 로그인이 필요합니다.” |
| 0:20 | `/gall/n/create` | “미니 갤러리 만들기입니다. 먼저 공개 또는 비공개를 고릅니다. 이후 변경이 안 된다고 하니 신중히요.” |
| 1:00 | 주소에 한글 입력 후 만들기 | “주소에 한글을 넣으면 만들기 버튼에서 이유를 알려 줍니다.” |
| 1:40 | 올바른 영문 주소·카테고리·동의 | “이름, 설명, 영문 주소, 카테고리, 동의까지 채웁니다.” |
| 2:40 | 성공 토스트 | “생성 요청이 완료되었습니다. 바로 열린 것처럼 보여도, 종류에 따라 심사가 필요할 수 있습니다.” |
| 3:20 | 다이어그램/안내 문장 | “신청이 접수되면 운영 쪽에서 승인 또는 반려합니다. 안내문에는 평일 점심에서 저녁에 처리한다고 되어 있습니다.” |
| 4:20 | 마이너와 한 줄 비교 | “마이너는 중복 주제 반려에 특히 주의하고, 미니는 중복이 비교적 자유롭다고 안내합니다.” |

## 화면 밖 설명(나레이션용 요약)

이용자 → 신청서 작성 → 웹 검사 → 신청 접수 → (필요 시) 심사 → 승인/반려 → 승인 시 갤 이용
