## 목표

초보자가 **회원가입 4단계**와 **로그인**을 화면만 보고 따라 할 수 있게 한다.

## 촬영 순서 (나레이션 한글)

| 시간(대략) | 화면 | 말할 내용 |
|------------|------|-----------|
| 0:00 | 헤더 | “디시인사이드 스타일 사이트에 오신 것을 환영합니다. 먼저 회원가입을 해 볼게요.” |
| 0:20 | `/sign/join/agree` | “약관에 필수 동의를 체크하고 다음을 누릅니다.” |
| 1:00 | `/sign/join/info` | “식별 코드는 한글이 안 됩니다. 영문과 숫자로 3자 이상 만드세요. 비밀번호는 8자 이상, 닉네임은 2자 이상입니다.” |
| 2:20 | `/sign/join/security` | “보안 코드를 확인하고 신청 완료를 누릅니다.” |
| 3:00 | `/sign/join/done` | “가입이 완료되었습니다.” |
| 3:20 | `/sign/login` | “같은 식별 코드와 비밀번호로 로그인합니다.” |
| 4:00 | 헤더(로그인 상태) | “이제 갤러리를 둘러보거나 만들 수 있습니다.” |

- 식별 코드에 한글 금지
